# Project 2025 Programming 282
--OVERVIEW--
A Windows Forms application developed in C# for managing superhero records at the fictional One Kick Heroes Academy. This project was completed as a group assignment for the Programming 2782 (PRG2782) module at Belgium Campus. The application uses file handling and Git version control to store, manage, and track superhero information

The Superhero Database System helps academy staff manage trainee hero records by replacing paper-based processes with a digital solution. The system allows users to add, view, update, and delete superhero records while automatically calculating hero ranks and threat levels based on exam scores.

--TECHNOLOGIES USED--
C#
Windows Forms
.NET Framework
File Handling (.txt files)
Git
GitHub
